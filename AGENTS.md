# Website editing

- This repository contains only ASTRAL's public website. The `docs/` directory is served by GitHub Pages.
- Use plain, direct wording and preserve the established design.
- Do not describe the scanner as open source or validated.
- Never add scanner code, datasets, benchmark questions, transcripts, scoring rubrics, prompts, private notes, credentials, or unpublished research.
- Keep publication limited to reviewed website files. Check image metadata and PDF attachments.
- Keep the canonical URL and sitemap at `https://astral.detection.bio/`.
- Check desktop and phone layouts after visual changes, and update the CSS query version after changing styles.
- Follow the user's current instructions about review and publication.
